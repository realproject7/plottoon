# Security Policy

PlotToon is a local desktop application that will interact with local files,
agent tools, image assets, wallets, and PlotLink publishing flows.

## Reporting a Vulnerability

If you discover a security issue, please contact the repository owner before
publishing details publicly.

Do not open a public issue that includes:

- Private keys
- Seed phrases
- API keys
- Wallet files
- Access tokens
- Private endpoint credentials
- Exploit details that could put users at immediate risk

## Supported Versions

PlotToon is not yet released. Supported version information will be added
after the first public build.
